# SubScript IDE (.sub15) - v2.9.5

Uma IDE moderna e intuitiva projetada para o desenvolvimento, execução e renderização em tempo real de scripts e projetos baseados na extensão `.sub15` (SubScript 2.9).

## 🚀 Recursos Principais

*   **Renderização em Tempo Real:** Visualize as alterações do seu código instantaneamente enquanto digita com o motor do SubScript 2.9.
*   **Gerenciamento de Arquivos:** Suporte completo para criar, abrir, salvar e exportar seus projetos diretamente para HTML estruturado.
*   **Snippets Rápidos:** Agilize seu fluxo de trabalho com blocos de código pré-configurados para rotas, popups, eventos de clique (`onclick`) e manipulação de arrays/variáveis.
*   **Console Integrado:** Área dedicada para depuração (debug) com visualização de saídas de `console.log()`, histórico de navegação e eventos de popups.

## 🛠️ Snippets Disponíveis

A IDE conta com atalhos prontos para acelerar o desenvolvimento de rotas e lógica:
*   `page = rota(param)`
*   `popup = nome`
*   `onclick.place`
*   `var` / `const`
*   `var = pagesarray[]`
